# ADR 0003: ギャラリー・モーダル・コピーフロー

ステータス: 承認済み

## コンテキスト

UIは、プロンプトを視覚的に探し出し、全文を素早くコピーするために使用される。

## 決定事項

- ギャラリーをメインのエントリポイントとして維持する。
- 詳細表示には、フォーカスされたモーダルを使用する。
- コピーアクションをモーダルの最上部に配置する。
- モーダル内にプロンプトを可読なテキストとして表示する。
- モーダル内にノードのリレーションを表示し、ユーザーが関連ノード間を移動できるようにする。

## 理由

- 画像優先のブラウジングは、長いリストを読むよりも高速である。
- 単一のコピーアクションにより、摩擦（フリクション）を最小化する。
- リレーションチップにより、ユーザーが一から作成することなくパーツを再利用できる。

## 影響

- UIはダッシュボード的ではなく、ユーティリティ優先を維持する。
- モーダルが再利用とコピーの主要な場所となる。
- 視覚的な例示は、プロンプトの再利用をサポートする場合にのみ重要となる。
