# ADR 0016: Quiet UI (2026年基準の最適化)

## ステータス

承認済み (2026-05-06)

## 文脈

プロジェクトの成長に伴い、UI/UXが「情報過多」および「主役の不在」に陥っていた。全ての要素に影をつけ、hoverで動かし、白いカードで囲う手法（旧来の「綺麗」なだけのUI）は、長時間の操作において視覚疲労を招き、本当に重要な「情報の階層」を不明瞭にしていた。

## 決定事項

Notion, Linear, Apple, Claude 等が採用している「静かなUI (Quiet UI)」を全面的に採用し、2026年基準のUXへと刷新する。

### 1. 情報密度の階層化 (3 Levels)

- **Primary**: 強いアクセント色や太字。ユーザーが最初に見るべき場所。
- **Secondary**: 白いカード (`#ffffff`) と極薄の影。独立した情報の塊。
- **Tertiary**: 背景なしのテキスト。補助的なラベルやメタデータ。

### 2. 配色設計 (Paper Tones)

- 単一の「白」を避け、`#fcfbf8` (Sidebar), `#f8fafc` (Main), `#f5f7fb` (Generator) 等の微細なトーン差（紙の質感）でエリアを分離する。
- 影 (`box-shadow`) を極限まで弱くし（`rgba(0,0,0,0.06)`）、境界線と背景色で階層を表現する。

### 3. タイポグラフィ

- 本文サイズを 15px〜17px に引き上げ、10px 以下のフォントを廃止。
- `line-height` を 1.6〜1.8 とし、余白による「読みやすさ」を優先する。

### 4. インタラクション

- `transform: translateY` 等の激しい動きを廃止し、`border-color` や `opacity` の滑らかな遷移 (120ms〜240ms) に統一する。
- スクロール時の物理的な挙動を改善 (`scroll-behavior: smooth`, `overscroll-behavior: contain`)。

### 5. 統合型モーダル

- 背景を暗転させて遮断するのではなく、透過とブラー (`backdrop-filter: blur(12px)`) を用いて、背後のページとのコンテキストを維持したまま詳細を表示する。

### 6. モーダル内回遊 (Navigable History)

- 詳細ビュー内でノード（タグ）をクリックして遷移した際、履歴スタックを保持する。
- 「戻る」ボタンを提供することで、深い探索を行っても元のコンテキストへ容易に復帰できる構造とする。

## 帰結

- 視覚的な「ノイズ」が減り、プロンプトの閲覧・コピーという主要な目的への集中力が高まる。
- 洗練された質感（高級感）が向上し、プロフェッショナルなツールとしての信頼性が生まれる。
- 激しい動きが減ることで、長時間使用時の疲労が軽減される。
