# ADR 0001: 静的JSONグラフDB

ステータス: 承認済み

## コンテキスト

`db/prompts.json` を、ブロックとテンプレートの唯一の正真のソース（Single Source of Truth）とする。

## 決定事項

- データベースを1つのJSONファイルに保持する。
- `blocks`、`templates`、`uses`、`related`、`variant_of`、`aliases` を使用してモデルを再利用可能にする。
- `build.py` でJSONをロードし、アプリのバンドルに埋め込む仕組みを維持する。

## 理由

- プロジェクト規模が小さいため、1つのファイルの方が編集やレビューが容易である。
- データ構造がすでにグラフのように動作しているため、明示的なグラフ用語を使用することで、新たなデータベースエンジンを追加することなく再利用性を向上できる。
- JSONファイルは静的ホスティングへのデプロイが単純である。

## 影響

- ブロックとテンプレートのIDは不変（ステーブル）に保つ必要がある。
- リレーションキーは実在するノードを指していなければならない。
- 現在の規模では SQLite やグラフデータベースは不要である。
