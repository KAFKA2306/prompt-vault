# ADR 0007: テンプレート一覧中心の最小トップ

ステータス: 提案

## コンテキスト

現在のトップ画面には、ブロック数・テンプレート数・画像例・使い方・ギャラリービューなど、目的が近い情報が複数並んでいる。  
しかし実際の利用では、テンプレート一覧だけ見れば概ね目的を達成できる。

ユーザーがこのサイトでやりたいことは、主に次の2つである。

1. 使いたいテンプレートを素早く見つける
2. 必要なら全文をコピーする

この2つに対して、トップの補助情報が多すぎると、一覧より先に説明を読む導線になり、画面の役割がぼやける。

## 決定事項

- トップの数値表示は置かない。
  - `blocks`
  - `templates`
  - `images`
- `画像例` の独立セクションは置かない。
- `使い方` の独立セクションは置かない。
- `ギャラリービュー` をトップの主導線にしない。
- テンプレート一覧を、トップの主たる閲覧・選択導線として扱う。
- コピーの主導線は維持する。
  - テンプレートの詳細表示の上部にコピー導線を置く

## 理由

- テンプレート一覧だけで、タイトル・目的・タグ・実例の有無が十分に判断できる。
- 補助セクションが多いと、同じ内容を別の形式で繰り返すことになり、画面が重くなる。
- 使い方の説明は価値が低い。
  - このサイトは複雑な学習対象ではなく、一覧から選んでコピーするだけの道具である
- ギャラリーとテンプレート一覧が併存すると、どちらを先に見るべきか迷う。
- 画像例は、テンプレートカードのサムネイルや詳細表示で代替できる。

## 影響

- トップはより短く、静かで、一覧中心になる。
- 一覧の表示密度が上がり、検索対象に早く到達できる。
- 初見ユーザー向けの説明量は減るが、このサイトではその損失より簡潔さの利得が大きい。
- 実装側では、トップに重複していたセクションと集計ロジックを削減できる。
- 既存の `ADR 0003` のうち、「詳細表示でコピーする」という決定は維持しつつ、`ギャラリー優先` の見せ方はトップ要件から外す。

## 補足

この決定は、`template list first` の設計に寄せるものであり、プロンプトの発見とコピーを最短にすることを優先する。  
視覚的な説明は、トップで増やすのではなく、テンプレートの個別カードと詳細表示に集約する。
