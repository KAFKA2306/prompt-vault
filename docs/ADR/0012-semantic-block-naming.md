# ADR 0012: ブロックの名称規則による意味的整合性の維持

## ステータス

承認済み

## コンテキスト

Prompt Vault の Blocks 調査において、内容（`content`）の包含関係はないものの、名称（`title`）が類似しているケース（例：`衣装` と `春衣装`、`話題切り替え` と `話題切り替え用バナー`）が多数確認されました。これらは「汎用と固有」や「挙動と視覚要素」といった明確な役割の棲み分けがなされていますが、将来的なブロック増加に伴う混同や構造の肥大化を防ぐため、名称レベルでの明文化が必要となりました。

## 決定

ブロックの `title`（表示名）に、その役割を示す接頭辞を付与する規則を導入します。

- **キャラクター:** `キャラクター: [名前]` (例: `キャラクター: KAFKA`)
- **衣装:** `衣装: [種別]` (例: `衣装: 春`)
- **形式:** `形式: [レイアウト名]` (例: `形式: 漫画レイアウト`)
- **行動:** `行動: [挙動名]` (例: `行動: 話題切り替え`)
- **文言:** `文言: [ジャンル]` (例: `文言: ゲーム`)
- **背景:** `背景: [シーン名]` (例: `背景: 読書`)
- **描画:** `描画: [スタイル名]` (例: `描画: 高精細 (Infographic)`)

これにより、ID（プログラム用の一意な値）を維持したまま、人間にとっての「単純明快な構造」を担保します。

## 影響

- **保守性**: 新規ブロック追加時にどの接頭辞を使うべきかが明確になり、意味的な重複を未然に防ぐことができます。
- **検索性**: ギャラリーや管理画面でのフィルタリング・検索が容易になります。
- **互換性**: ID は変更しないため、既存のテンプレートや生成済みの `generated_prompt` に影響を与えません。
- **Zero-Fat**: 専門化されたブロックを「不要な重複」と誤認して削除することを防ぎつつ、真に不要な重複を検出しやすくします。
