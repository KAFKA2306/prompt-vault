# ADR 0027: エージェント・ハーネス監査チェックリストの採用

## ステータス

承認済み (Accepted)

## コンテキスト

AIエージェントの信頼性を担保するためには、モデル単体の性能よりも、それを包摂する実行環境（ハーネス）の品質が決定的な要因となる。実運用において、リソースの暴走、状態の不整合、セキュリティ侵害、および非決定的な挙動を防ぐための構造的な監査フレームワークが必要である。

## 決定事項

[docs/HARNESS_CHECKLIST.md](docs/HARNESS_CHECKLIST.md) に定義された「エージェント・ハーネス監査チェックリスト（ETCLOVG）」を、システムの設計・運用・監査の標準基準として採用する。

以下の 7 つのレイヤー（ETCLOVG）を監査の柱とする：

1. **Execution (実行環境)**: 隔離技術と復旧の決定論。
2. **Tool Interface (ツール層)**: 統合境界と副作用の制御。
3. **Context & Memory (コンテキスト)**: キャッシュ効率とメモリ階層。
4. **Lifecycle (ライフサイクル)**: 状態遷移と再開可能性。
5. **Observability (可観測性)**: トレースと意図の可視化。
6. **Verification (検証)**: 根拠に基づく多層判定。
7. **Governance (ガバナンス)**: 最小権限と宣言的ポリシー。

また、実戦的なガードレール（コスト爆発、無限ループ、ハルシネーション検出等）を網羅した「実戦追加チェック」も同時に適用する。

## 影響

- すべての自律タスク、自動化パイプライン、およびエージェントの行動は、本チェックリストに基づいて監査される。
- `AGENTS.md` にハーネス優先の原則（Harness-First）を再定義し、本チェックリストへの参照を追加する。
