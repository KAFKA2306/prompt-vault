# ADR 0002: ビルド時バリデーション

ステータス: 承認済み

## コンテキスト

アプリはビルド時およびローカルサーバー起動時にデータベースを読み込む。

## 決定事項

- ブロックIDの重複を検証する。
- テンプレートIDの重複を検証する。
- `template.blocks` の参照を検証する。
- `template.uses` の参照を検証する。
- `block.related` および `block.variant_of` の参照を検証する。

## 理由

- 参照切れは早期にエラーとして検出されるべきである。
- UIがサイレントに壊れるよりも、ビルド時のエラーの方が修正が容易である。
- スキーマシステムを導入せずに、バリデーションによってデータモデルのシンプルさを維持する。

## 影響

- データベースの編集には有効な参照が必要となる。
- 新しいノードは、リンクされる前に作成される必要がある。
- ビルドは単なるファイルコピーではなく、安全性チェックの役割を果たす。
