# ADR 0014: WebP 画像最適化による通信量の削減

## 背景

Prompt Vault は画像中心のギャラリーサイトであり、100枚を超えるテンプレートを掲載している。従来の PNG 形式では、全件閲覧時に約 268 MB の通信が発生し、モバイルデータ通信環境においてユーザーに大きな負担を強いていた。

## 決定事項

ビルドパイプライン（`build.py`）において、すべての PNG 画像を自動的に WebP 形式に変換し、フロントエンドに配信するデータベース内のパスも自動的に書き換える機能を実装した。

## 証拠（定量評価）

2026年5月時点、全 135 テンプレート（アクティブ画像）を対象とした実測値。

| 指標 | 変換前 (PNG) | 変換後 (WebP) | 削減率 |
| :--- | :--- | :--- | :--- |
| **合計サイズ** | **267.94 MB** | **25.85 MB** | **90.4% 削減** |
| **平均サイズ** | **2,143 KB** | **207 KB** | - |

## 効果

- **通信コストの劇的な低減**: モバイルユーザーのデータ消費量を 1/10 以下に抑制。
- **LCP (Largest Contentful Paint) の改善**: 画像のダウンロード時間が短縮され、ページの体感速度が向上。
- **ストレージ効率**: デプロイパッケージ（`dist/`）の軽量化。

## ステータス

承認済み。`build.py` および `app.py` に実装済み。
