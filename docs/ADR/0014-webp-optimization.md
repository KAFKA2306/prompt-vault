# ADR 0014: WebP 画像最適化による通信量の削減

## 背景

Prompt Vault は画像中心のギャラリーサイトであり、100枚を超えるテンプレートを掲載している。従来の PNG 形式では、全件閲覧時に約 268 MB の通信が発生し、モバイルデータ通信環境においてユーザーに大きな負担を強いていた。

## 決定事項
1. **自動変換の導入**: `build.py` 内に Pillow を使用した WebP 変換処理を組み込む。
2. **弾力的な設計 (Resilient Design)**:
   - Pillow がインストールされている環境（GitHub Actions 等）では WebP 変換を行い、パスを `.webp` に書き換える。
   - Pillow がない環境（標準の Cloudflare 等）では、自動的に PNG コピーと `.png` パス維持にフォールバックする。
3. **パスの自動書き換え**: ビルド時に `app.js` 内の画像パスを、生成されたファイル形式（.webp または .png）に合わせて動的に置換する。

## 理由
- **ユーザー体験の向上**: 最大 90% の軽量化により、モバイル環境での閲覧を劇的に高速化する。
- **デプロイの安定性**: 環境依存によるビルド失敗を防ぎつつ、利用可能な環境では最大限の最適化を享受する。

## 証拠（定量評価）

2026年5月時点、全 135 テンプレート（アクティブ画像）を対象とした実測値。

| 指標 | 変換前 (PNG) | 変換後 (WebP) | 削減率 |
| :--- | :--- | :--- | :--- |
| **合計サイズ** | **267.94 MB** | **25.85 MB** | **90.4% 削減** |
| **平均サイズ** | **2,143 KB** | **207 KB** | - |

### 特定ファイルにおける実測例 (ls -l 証拠)

| ファイル名 | 変換前 (PNG) | 変換後 (WebP) | 削減率 |
| :--- | :--- | :--- | :--- |
| `005_announcement_thumbnail` | **1,987,602 bytes** | **158,124 bytes** | **92.0% 削減** |

## 効果

- **通信コストの劇的な低減**: モバイルユーザーのデータ消費量を 1/10 以下に抑制。
- **LCP (Largest Contentful Paint) の改善**: 画像のダウンロード時間が短縮され、ページの体感速度が向上。
- **ストレージ効率**: デプロイパッケージ（`dist/`）の軽量化。

## ステータス

承認済み。`build.py` および `app.py` に実装済み。
