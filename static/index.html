使い方

画像生成プロンプトを探して、コピーする。

Prompt Vault は、ギャラリーとモーダルでプロンプトを扱うサイトです。ブロック単位で分けてあるので、テンプレートごとの中身を確認できます。

検索 タイトル / 目的 / ブロックID で絞り込み
コピー モーダル上部のボタンから全文を即コピー
再利用 ブロックを分けて、別テンプレートに組み直しやすい
